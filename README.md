# EIMEIスクールデータ

学校名で検索すると、その学校の大学合格者数・指定校推薦・部活動・入試応募状況・選抜基準・併願例・帰国生入試をまとめて見られるページです。
出典は「2027年度入試 受験案内 付録（データ＆データ編）」で、数値・名称は原本のとおりです。

- `public/index.html` … ページ本体（データも埋め込み済み、1ファイルで動きます）
- `vercel.json` … Vercel の設定

## 公開（Vercel）
Vercel で「Add New → Project」からこのリポジトリを選び、設定は変えずに Deploy するだけです（Framework Preset: Other、Output Directory: public）。
